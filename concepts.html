Todo App Concepts Playground

React Core Concepts

This project loads React directly via Content Delivery Networks (CDNs) and Babel standalone. This setup avoids heavy build toolchains, letting you execute JSX natively in any browser for rapid learning and prototyping.

1. State Management

State represents dynamic data that changes over time. Our Todo app tracks three pieces of state: the list of tasks, the text input value, and the active filter category.

const [todos, setTodos] = React.useState([]);
const [inputValue, setInputValue] = React.useState('');
const [filter, setFilter] = React.useState('all');

2. Event Handling

React handles user interactions using synthetic event handlers. We capture typing via onChange and state updates via onClick listeners.

<input
    type="text"
    value={inputValue}
    onChange={(e) => setInputValue(e.target.value)}
    placeholder="Add a new task...."
/>
<button onClick={() => setFilter('active')}>Active</button>

3. List Rendering & Dynamic UI

React transforms arrays of data into UI elements using JavaScript's .map() method combined with conditional class binding for styling states.

{filteredTodos.map((todo) => (
    <li key={todo.id} className="todo-item">
        <span className={`todo-text ${todo.completed ? 'completed' : ''}`}>
            {todo.text}
        </span>
    </li>
))}
